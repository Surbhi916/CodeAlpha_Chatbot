# CodeAlpha_Chatbot

## Description

A Python-based Chatbot developed as part of the CodeAlpha Internship Program. This chatbot interacts with users through a simple conversational interface and provides automated responses to user queries.

## Features

- Interactive conversation with users
- Predefined responses for common questions
- User-friendly interface
- Easy to customize and extend
- Beginner-friendly Python project

## Technologies Used

- Python 3

## How to Run

1. Install Python on your system.
2. Download or clone this repository.
3. Open the project folder.
4. Run the program using:

python chatbot.py
